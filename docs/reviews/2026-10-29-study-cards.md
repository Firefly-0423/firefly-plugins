# 学习卡片插件提交前检查

检查范围：PR #3 相对插件仓库 main `61222623c7c8741b01424e566da96e91ad2208c2` 的全部插件源码、目录记录、说明及测试。插件为 Firefly Plugin API v1；不联网、不执行命令、不依赖 Anki。

## 发现与修复

- 写入工具在参数校验失败时也返回 `effectState: unknown`，会让宿主误认为发生了不确定写入。现在仅存储写入抛错时报告 unknown；未尝试写入的错误报告 not_applied。回归测试先失败后通过。
- 存档校验未拒绝重复卡片 ID 和负数/超范围复习间隔。现在拒绝这些存档，并在保存前使用副本，避免原对象在失败路径上被改变。回归测试先失败后通过。
- 已发布的 0.1.0 保持不变，修订源码版本为 0.1.1。本轮只提交 PR，不发布 Release。

## 接口与影响范围

七个工具通过 `ctx.registerTool` 注册，全部使用插件 ID 前缀；读操作声明 fs-read，写操作声明 fs-write，并走宿主权限调度。更新、删除和评分要求当前卡片 revision。插件代码只调用宿主私有存储，额外文件检查只用于识别宿主读取失败的已有存档；不接收文件路径或网络地址。

存储原子替换由 Firefly storage 实现提供；当前插件没有跨 Firefly 进程共享一个存储目录的锁，因此本轮不宣称支持多进程同时编辑同一插件数据。卡片内容会进入当前模型对话，说明中已标明。复习使用简单间隔规则，不宣称 Anki / FSRS 兼容。
