# 原生字幕与配色工具设计

本轮由用户授权调研、设计并提交插件 PR，按仓库中 Claude 已有形式实现。以下范围是本轮提出的首版选择，供 PR 审查，不表示用户逐项指定了全部参数。

## 目标与方案

字幕工具处理已经存在的字幕文本，颜色工具处理已知前景/背景色。均采用 Firefly API v1 的纯计算工具；不建立窗口、不需要宿主内部模块、不增加 deps，不调用模型。基础包仍是 LICENSE/README.md/index.cjs/manifest.json，目录能力在 catalog.json。

考虑的其他方案：直接集成 subtitle.js 的流式运行时会带入 npm 依赖；嵌入完整字幕工作台会要求文件授权和窗口适配。首版选有界文本计算，返回给当前对话；需要保存时由已有宿主工具处理。颜色方面拒绝通用 CSS 求值与屏幕取色，采用不透明 sRGB hex，避免隐藏的背景合成假设。

## 字幕工具

- `subtitle-tools_inspect({text})`：识别基础 SRT/WebVTT，报告条数、最早开始/最晚结束、重叠和乱序。最多输出 100 项问题，并报告完整数量和省略数。不自动改序。
- `subtitle-tools_transform({text,format,offsetMs?})`：正偏移延后、负偏移提前；输出 SRT 或 WebVTT。默认偏移 0。SRT 重新顺序编号，多行正文与 Unicode 保留，换行统一 LF。
- 输入 200000 UTF-16 码元、2000 cues，输出 250000 码元。单次偏移 ±7 天，结果时间必须位于 00:00:00.000–99:59:59.999；超界拒绝整个结果，不压到零或丢弃字幕。
- WebVTT 支持小时省略、cue ID、时间行 settings；NOTE/STYLE/REGION 块拒绝。转 SRT 时存在 WebVTT 标题、非数字 ID 或 settings 也拒绝，避免静默丢信息。正文中的标记只作为字符串保留，不承担样式渲染或跨格式标签语义转换。
- 不做 ASS、翻译、转写、编码识别、视频烧录或音画同步的自动听觉判断。

## 颜色对比度

- `color-contrast_check({foreground,background})`：只接受 #RGB/#RRGGBB，返回规范化颜色、六位小数比值和四档文字 AA/AAA 布尔结果。
- `color-contrast_palette({pairs})`：最多 50 对，一次返回各项及普通文字 AA 失败数量。无效项让整批失败。
- 线性化阈值 0.04045；亮度权重 0.2126/0.7152/0.0722；比值 (较亮+0.05)/(较暗+0.05)。判定使用未舍入比值。AA 普通文字≥4.5、大字≥3；AAA 普通≥7、大字≥4.5。
- 大字资格由使用者判断实际字号/字重；不承诺整页 WCAG 合规。不解析透明度、渐变、图片背景或 Display-P3。

## 安全、生命周期与分发

文本和颜色均为不可信输入，边界验证拒绝未知参数、错误类型和超限；不执行输入中的标签或表达式。两个入口无 require、DOM、文件、网络、计时器和环境读取，可在无 Node API 的 VM 中运行。

register 拒绝重复激活；若第二个工具注册失败，注销此前已注册的第一个工具；unregister 幂等且支持重新启用。工具元数据与 Claude 原离线插件一致：safe / read / none。

源码、设计、测试及生成 registry 一起提交 PR。构建器/旧插件字节/发布工作流不变；本轮不执行发布或自动合并。保留既有 main 内容，PR 待审核后再按用户要求清理已合并分支。

## 验收

1. 先写行为测试并观察实现缺失导致的失败，再实现通过。
2. 字幕用 BOM/CRLF/Unicode、多行、小时省略、ID/settings、重叠、边界偏移、格式转换和明确拒绝有损输入作为测试。
3. 颜色用 21:1、1:1、阈值两侧、前后景互换、批量和非法透明度作为测试。
4. 从真实 ZIP 取出入口，在没有 Node API 的 VM 中执行，而不只测试源码。
5. 使用当前 Firefly installer、loader、createContext 做隔离宿主组件验证。它不等于完整应用 UI 或真实模型选择工具的端到端验收。
6. npm test/build/check 及 Windows/Ubuntu CI 通过；原七个插件版本和 SHA 不变。
