# 学习卡片

Firefly 原生插件，无需安装 Anki、MCP 服务或额外运行时。启用后可在对话中创建、浏览、修改和删除问答卡，读取新卡和待复习卡，并根据用户评分记录复习结果。数据保存在 Firefly 的插件私有存储中，不联网；卡片内容会进入当前对话及所用模型。

首版最多保存 1000 张卡，每次最多读取 40 张。评分 1（重来）间隔 10 分钟，2（困难）间隔 1 天，3（良好）至少 3 天并逐步延长，4（简单）至少 7 天并逐步延长，最长 365 天。这是简单的本地复习规则，不是 Anki 或 FSRS 的算法，也不与 Anki 数据同步。

插件默认停用。创建和评分会修改本地学习数据；请先确认。停用插件不会删除卡片。当前为开发构建，在线市场安装需要先发布对应 Release ZIP。
