# 语言学习（study-cards）

Firefly 原生学习插件：阅读文章、选择词语查词、收藏词义与例句、用卡片复习。支持英语、日语、韩语、法语、德语、西班牙语，中文界面。保留旧版七个学习卡工具，无需 Anki、AnkiConnect、MCP 或其他运行服务。

## 使用

插件源码位于本仓库，运行 npm run build 生成 dist/study-cards-0.2.0.zip，通过 Firefly 插件页的本地导入入口安装，默认停用。在插件管理中启用后，点击打开进入独立学习窗口。需要提供 API v1、插件资源协议、Node 24 内置 SQLite 和 Electron 本地窗口的 Firefly 版本；缺少能力时明确报错，不自动下载运行时。

本次交付为源码 PR 和本地预览，不发布 Release。当前核对的 Firefly-Agent main 中，在线市场仍通过 registry.json 的 Release URL 下载；因此源码合并或目录版本更新不代表该在线下载已可用。仓库直装能力须以使用中的宿主实际入口为准，不能将本地导入验收冒充在线市场安装验收。

1. 在「词典」导入有权使用的本地 Yomitan format 3 ZIP；选择词典原文语言，检查预览与警告，再确认添加。也可添加小型原创演示词典体验流程。
2. 「阅读」中粘贴文章、打开 UTF-8 .txt/.md（最多 1 MiB），或试读示例。选择原文语言，在阅读区选词；也能在右侧输入查询。
3. 检查释义与来源，点「留在生词本」，编辑选定释义、例句后保存；一次保存同时创建生词和学习卡。
4. 在「生词」搜索、筛选、编辑、删除；「复习」选择新卡或到期卡，揭晓答案后按真实感受评分。
5. 保存文章以保留阅读位置。右上角导出卡片、生词、文章和词典信息 JSON；词典原始内容请保留本地 ZIP。

## 能力与限制

- 划词作用于插件自己的阅读区；不会在 Chrome/Edge 任意网页注入脚本，不抓取远程网页。
- 精确匹配使用 Unicode NFC，拉丁字母支持大小写候选；原词命中优先。没有完整分词、活用或词形还原。未命中时尝试原形或调整选区，不生成猜测释义。
- 释义语言由词典决定，中文界面不代表所有词典都有中文释义。每条结果显示词典名、版本和释义语言。
- 演示词典是少量原创词条，用于操作体验，不是完整词库，也不代表真实词典覆盖率。
- 合成朗读只使用系统实际提供、语言匹配且标记本地的语音。无可用语音时按钮禁用并说明原因；不会联网获取音频。系统合成语音不是流萤声线。
- 词典图片、音频、样式、词频、音调及外部链接不会加载。结构化释义安全地转为纯文本；不支持内容在导入预览中报告。词典自身的许可和来源由用户核实，不随插件再分发第三方词库。
- 本地词典索引和导入在后台 worker 执行。ZIP 上限 200 MiB、实际总展开 1 GiB、单 bank 64 MiB、2 百万词条；实际性能依设备和词典结构而异。拒绝路径穿越、重复别名、链接、加密、CRC 错误和超限。取消或失败不改变现有词典，确认后才添加。
- 复习沿用原规则：重来 10 分钟；困难 1 天；良好至少 3 天或上次间隔的 2 倍；简单至少 7 天或 2.5 倍；上限 365 天。不是 Anki/FSRS 算法。卡片总量维持 1000 张。

## 数据与升级

数据保存在 Firefly 提供的插件私有目录。首次升级校验 cards-v1.json，在 SQLite 事务中保留原卡片 ID、版本、牌组、到期时间、间隔、复习次数，和迁移标记一并提交。原 JSON 不删除、不改写；损坏数据拒绝迁移，不能当空库覆盖。

0.2.0 的新增修改写入 learning.sqlite。降级到 0.1.1 仅能读到保留的旧 JSON，**不支持无损降级**；降级前导出新数据。导出目前为可读备份，不提供一键恢复导入。生词与卡片原子保存，operationId 防止重复提交；修改、删除、评分都检查 revision。

文章默认留在本地，不自动进入聊天模型。用户明确调用工具返回的卡片或查询内容才会进入对应对话。插件主进程具有宿主权限；阅读窗口使用隔离、沙箱、窄 IPC、资源白名单与网络拒绝，这不等于整个插件处于操作系统沙箱。

## 工具

保留 study-cards_create / new / due / review / update / delete / list 原有参数及返回主字段。新增：

- study-cards_lookup({ language, term, limit? })：查已启用的本地词典。
- study-cards_collect({ language, term, reading?, meaning, context?, dictionaryId?, operationId })：保存确认的词义与例句；同语言同词同义复用现有卡。

词典和文章文件只能通过窗口的原生选文件入口授权，工具没有任意路径读取能力。工具风险按只读/写入分别声明，由 Firefly 调度。
